02 / ANALYSE LOCALE

Votre enregistrement

Les mains et leurs 21 points anatomiques sont suivis automatiquement.

Paramètres d’analyse

La bande est réduite si la cadence réellement analysée est insuffisante. Les 30 premières secondes au maximum sont traitées.

La lecture est ralentie pendant le calcul. Gardez cette page ouverte ; l’analyse peut prendre quelques minutes.

03 / RÉSULTATS

Ce que le signal révèle

Mesure expérimentale — aucun diagnostic ne peut être établi à partir de ce résultat. Un mouvement de caméra peut imiter un tremblement de la main.

Les points superposés à la vidéo correspondent à l’image analysée la plus proche (écart maximal de 0,1 s).

Local, explicite, expérimental.

Aucune vidéo ni coordonnée anatomique n’est envoyée à un serveur. Aucun compte, aucune télémétrie. Fermer ou effacer la vidéo libère les données de la session ; seuls les exports que vous téléchargez restent sur votre appareil.

Ce prototype n’est pas un dispositif médical diagnostique validé. Le traitement local ne constitue pas une validation réglementaire pour un usage clinique.
